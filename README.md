Liquidity Risk Monitoring & Stress Testing
Project Overview
This project analyzes liquidity risk through cash flow monitoring and scenario-based stress testing using Tableau.
Business Objectives
Monitor cash inflows and outflows.
Analyze net cash flow trends.
Compare baseline and stressed cash flow conditions.
Assess stress impact on liquidity.
Identify potential liquidity pressure.
Tools
Tableau
Excel / CSV
Python or SQL (if applicable)
Key Metrics
Cash In
Cash Out
Net Cash Flow
Stressed Inflow
Stressed Outflow
Stressed Net Cash Flow
Stress Impact
Dashboard
The Tableau dashboard visualizes cash flow trends and stress scenario impacts.
Key Insights
To be completed based on the actual dashboard results.

Limitations

Results depend on the assumptions and structure of the dataset. This project is for analytical and educational purposes and does not represent an official assessment of a real bank.
